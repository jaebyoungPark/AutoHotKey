1. 먼저 OpenTabletDriver.Daemon.exe 실행해서 내컴퓨터에 연결된 태블릿을 인식시켜.

2. OpenTabletDriver.UX.Wpf.exe 를 실행해.

3. Plugin Manager 에서 Window Ink 설치.

3. Output 에서 Window Ink Relative Mode 선택. save as 로 json 파일 저장. 그럼 적용됨. 

3. 블렌더 Tablet API 확인: Edit > Preferences > Input > Tablet에서 Tablet API가 Automatic 또는 Windows Ink로 되어 있는지 확인합니다.
   Windows Ink 로 설정해야함.
   
4. 자동토글링도 오토핫키로 구현 가능한데, Window Ink Relative Mode 만으로도 일단은 충분해서 구현 안함.
