;========================= 폐기된 내용들
; XP-Pen 설정시 유의사항
; 내 XP-Pen 설정에서 정말 중요한 점. Window Ink 를 체크해야만 블렌더 페인팅에서 필압에 따라 radius 가 적용됨. 마우스 모드를 동시에 적용하면
; 커서 이동은 편하지만, 치명적인 문제가 있는데 화면 컨트롤 시 렉 또는 버벅임이 발생함.
; 마우스 모드만 켜면 radius 등 필압적용 안되므로 블렌더 사용시 무조건 꺼야됨.
; 결론 : 불편하더라도 window ink 만 켜라. 코드에는 문제가 없다.

;========================= 사용할 내용들 

1. 먼저 OpenTabletDriver.Daemon.exe 실행해서 내컴퓨터에 연결된 태블릿을 인식시켜.

2. OpenTabletDriver.UX.Wpf.exe 를 실행해.

3. Plugin Manager 에서 Window Ink 설치.

3. Output 에서 Window Ink Relative Mode 선택. save as 로 json 파일 저장. 그럼 적용됨. 

4. 블렌더 Tablet API 확인: Edit > Preferences > Input > Tablet에서 Tablet API가 Automatic 또는 Windows Ink로 되어 있는지 확인합니다.
   Windows Ink 로 설정해야함. 
  
5. Mouse Utils 도 Plugin Manager 에서 받아라. 마우스처럼 인식해서, 블렌더 뷰포트에서 끝을 넘어갈때도 계속 화면을 컨트롤 할수 있게 해줌.
   
6. 자동토글링도 오토핫키로 구현 가능한데, Window Ink Relative Mode 만으로도 일단은 충분해서 구현 안함.
